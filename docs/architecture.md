# Architecture

## Monorepo Layout

| Path                         | Framework      | Notes                          |
| ---------------------------- | -------------- | ------------------------------ |
| `apps/web`                   | TanStack Start | Main app, port 3000            |
| `apps/docs`                  | Next.js        | Documentation, port 3001       |
| `packages/ui`                | React          | Shared components (`@repo/ui`) |
| `packages/eslint-config`     | —              | Shared ESLint configs          |
| `packages/typescript-config` | —              | Shared TypeScript configs      |

## Key Conventions

- **Path alias:** `@/` maps to `apps/web/src/`
- **Package imports:** Import shared UI as `@repo/ui/button` (barrel-less, one component per import)
- **Environment:** `VITE_CONVEX_URL` required in `apps/web/.env.local`

## Generated Files — Never Edit

- `apps/web/convex/_generated/` — Convex types and API (regenerated by `pnpm convex`)
- `apps/web/src/routeTree.gen.ts` — TanStack Router route tree (regenerated on dev)

## Legacy Directory

Root `/convex/` is leftover boilerplate. The real backend lives at `apps/web/convex/`.
