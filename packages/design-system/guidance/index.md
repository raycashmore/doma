# Doma patterns

Find guidance for a feature before choosing its native implementation. Patterns explain behaviour, platform differences and evidence gaps. Each framework keeps its own renderer.

Start with [List overview and access](/patterns/list-overview-and-access.html), or [browse patterns](/patterns/). Search also finds states such as unavailable access and cached freshness.

The first pattern is proposed. Its current source and test references help you inspect existing behaviour; native token adoption is implemented; four annotated Pencil examples and their live token proof are available. Launcher/TalkBack checks and maintainer promotion remain pending. Read the gaps before treating a reference as a verified example.

[Foundations](/foundations.html) explains the two candidate token roles and intentional native differences. [Contribution guidance](/contributing.html) explains changes and approval.

This guide uses generic examples only. Browse it locally or at [the protected guide](https://doma-design-guide.vercel.app) with your authorized Vercel account. Hosted access does not approve the proposed pattern or close its device and accessibility gaps.
